# resheph.nvim
Live and drink. A Caves of Qud inspired theme for NeoVim

## Installation

```
vim.pack.add({
  { src = "https://github.com/BrendanTimmons/resheph.nvim" },
})

vim.cmd.colorscheme "resheph"
```
